# Security / Segurança

**English:** Do not publish vulnerabilities, production credentials or real documents in GitHub issues. Use a private GitHub security advisory when enabled, or another secure channel specified by the maintainer.

**Português:** Não publique vulnerabilidades, credenciais de produção nem documentos reais em issues. Utilize uma comunicação privada por GitHub Security Advisory, se disponível, ou outro canal seguro indicado pelo mantenedor.

This repository is an infrastructure scaffold, **not a production-ready financial document vault**.

Este repositório é uma estrutura inicial, **ainda não é um cofre de documentos financeiros pronto para produção**.
