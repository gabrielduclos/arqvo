# Contributing / Contribuindo

### English
Open an issue for large changes, use a focused pull request, include tests, and update both English and Portuguese documentation if behavior changes.

### Português
Abra uma issue para grandes mudanças, envie pull requests objetivos, inclua testes e atualize as documentações em inglês e português quando modificar o comportamento.

## Run checks / Verificações
```bash
cd apps/api
npm install
npm test
```

Do not include real personal/financial documents, database URLs or secrets. Contributions are licensed under MIT.

Não inclua documentos pessoais/financeiros reais, strings de conexão ou segredos. Contribuições sob a licença MIT.
